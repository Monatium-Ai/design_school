# 디지털매체 법적규제 6차시 — AI와 저작권

> 한 줄 요약: **AI를 써도 저작권의 중심은 사람이다.** 사람의 창작적 기여가 있어야 권리가 생기고, 남의 권리(저작권·초상권·상표권 등)를 침해하면 AI를 썼어도 책임은 사람에게 있다.

---

## 1. 핵심 개념

| 개념 | 뜻 |
|---|---|
| **저작권** | 책·그림·음악 등 창작물을 보호하는 권리 |
| **복제** | 다른 사람의 저작물을 복사하는 행위 |
| **AI 학습** | AI가 많은 데이터를 이용해 패턴을 학습하는 과정 |
| **공정이용** | 일정한 조건에서 저작물 이용을 허용하는 법리 |
| **시장 피해** | 원저작물의 판매·라이선스 시장 등에 미치는 영향 |
| **라이선스** | 저작물을 이용하기 위해 권리자로부터 받는 허락 |
| **인간 창작자** | AI 시대에도 저작권의 중심이 되는 중요한 개념 |

---

## 2. 자료별 관련 권리

디자인에 자료를 가져다 쓸 때, **어떤 권리를 확인해야 하는지** 먼저 떠올리기.

| 자료 | 관련 권리 |
|---|---|
| 인터넷 사진 | 저작권 |
| 유명 캐릭터 | 저작권 · 상표권 |
| 폰트 | 라이선스 |
| AI 이미지 | AI · 저작권 |
| 친구 사진 | 초상권 · 개인정보 |
| 유명 가수의 음악 | 저작권 |

- 포인트: 하나의 자료에 **권리가 여러 개** 걸릴 수 있다 (예: 캐릭터 = 저작권 + 상표권).
- 폰트는 "무료"라도 **상업적 이용 가능 여부**를 라이선스에서 확인해야 한다.

---

## 3. 디지털디자인 핵심 지식 8개

### A. AI와 저작자 — "누가 권리를 갖는가?"

**① AI는 저작자가 아니다.**
- AI 자체를 인간 저작자와 동일하게 보는 것은 적절하지 않다.

**② AI를 사용했다고 저작권이 무조건 없어지는 것은 아니다.**
- **인간의 창작적 기여**가 중요하다.

**③ 프롬프트를 입력했다고 무조건 저작권자가 되는 것은 아니다.**
- 프롬프트와 결과물에 대한 **인간의 창작적 통제 정도**를 살펴봐야 한다.

### B. 침해 위험 — "무엇이 문제가 되는가?"

**④ AI가 학습한 자료도 법적 쟁점이 될 수 있다.**
- 저작권자의 작품을 AI 학습에 이용하는 문제가 별도로 존재한다.

**⑤ AI 결과물이 기존 작품과 너무 비슷하면 문제가 될 수 있다.**
- AI라는 도구를 사용했다는 이유만으로 저작권 침해 문제가 사라지는 것은 아니다.

**⑥ 다른 사람의 얼굴을 AI에 넣는 것은 별개의 문제다.**
- 저작권 외에 **초상권 · 인격권 · 개인정보** 등을 검토해야 한다.

### C. 디자이너의 실무 태도 — "어떻게 대비하는가?"

**⑦ AI가 작성한 문구도 사람이 검증해야 한다.**
- 특히 **광고**에서는 사실 여부를 확인해야 한다.

**⑧ 디자이너는 AI 사용 기록을 남기는 것이 좋다.**
- 사용한 AI 도구
- 입력 자료
- 프롬프트
- 생성 결과
- 수정 과정
- 최종 디자인

> 왜 기록하나? → ②③에서 말한 **"인간의 창작적 기여/통제"를 증명**할 근거가 되기 때문.

---

## 4. 개념 연결 정리

```
AI 학습 ──(④ 학습 데이터 쟁점)──▶ AI 결과물
                                   │
            ⑤ 기존 작품과 유사? ───┤── 복제·저작권 침해 위험
            ⑥ 타인 얼굴 사용?  ───┤── 초상권·인격권·개인정보
                                   │
            ①②③ 인간의 창작적 기여 ─▶ 저작권 인정 여부
                                   │
            ⑦ 검증 + ⑧ 기록 ────────▶ 디자이너의 책임 있는 사용
```

- **공정이용** 판단 시 **시장 피해**(원작 판매·라이선스 시장에 영향이 있는가)가 중요한 기준이 된다.
- 권리자 허락이 필요하면 → **라이선스**를 받는다.
